- `tools/differential` isolates concurrent runs (#192): per-run base worktrees and default output directories carry random suffixes, and each pair chooses and reports five free ports outside the registry after building, just before recording. The per-SHA base build cache remains shared under an exclusive `fcntl.flock` on `<target>/.differential.lock`, held through both builds and copies of `bsv-wallet` and `bsv-wallet-mcp` to the run's output directory; recordings use those copies. A head built by the tool is copied too and needs a private `CARGO_TARGET_DIR`. Each run removes only its own worktree. `--ports A,B,C,F,S` requests explicit ports, with registry ports refused by name. Cross-run comparisons normalize recorded ports by role, but are not zero tests because their root keys differ; a zero test is within one run. Regression tests cover occupied ports, same-second output paths, overlapping worktree cleanup, explicit-port validation, cache replacement after copying, lock release on failure, head copies, late port selection and cross-run comparisons; the suite remains 24 scenarios. The CI job is unaffected: one comparison pair per job.
