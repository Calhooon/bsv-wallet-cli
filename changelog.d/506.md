- **The library's `GateOptions` and `ServerConfig` gain a public field, `header_retry_pause: Duration` (#506)**: the spend gate's pause before its one header re-read, which before was the constant `spend_gate::HEADER_RETRY_PAUSE` alone. `GateOptions::default`, `GateOptions::from_config`, `ServerConfig::default` and `ServerConfig::from_config` set it to `HEADER_RETRY_PAUSE` (2 s, unchanged and never configured), and `make_router` and `make_router_owing` serve the gate with `ServerConfig`'s value through the crate's own `server::gate_options` (not public). A struct literal of either type outside the crate must now name the field (or take `..Default::default()`); the tests shorten it and the wire harness's worlds set it to zero. No served behaviour changed: the daemon and `serve` pause the same 2 s.
