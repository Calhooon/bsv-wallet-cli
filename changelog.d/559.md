- **A whole incremental Nightly re-bases the record (#559)**: an incremental night whose changed set is the whole set judges every floored file at one sha, so its record's `base` names its own run and commit (`"whole": true`, "this run, the changed set the whole set"); the next night's plan diffs against it and its score carries from it, where a night that judged a subset keeps the base it carried from. No floor moves on an incremental night; the shard count stays a resource setting.
